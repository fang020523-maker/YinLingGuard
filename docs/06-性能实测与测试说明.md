# 性能实测与测试说明

**作品**：银龄守护（com.yinling.guard v1.0.0）
**测试环境**：HarmonyOS 7.0.0（API 26）本地模拟器 YinLingPhone（1320×2232）；DevEco CLI 全命令行构建（hvigor release 26.0.0.851）；UI 自动化验证（uitest dumpLayout + 坐标注入）
**测试日期**：2026-10-26

## 一、性能实测

### 1.1 冷启动时延（Ability onCreate → 系统首帧绘制完成）

| 轮次 | onCreate | 首帧（WMS NotifyCompleteFirstFrameDrawing） | 时延 |
|---|---|---|---|
| 1 | 15:24:25.142 | 15:24:25.367 | 225 ms |
| 2 | 15:24:45.023 | 15:24:45.271 | 248 ms |
| 3 | 15:24:48.664 | 15:24:48.930 | 266 ms |

**均值 ≈ 246 ms**（force-stop 后冷启动，含窗口创建与 ArkUI 首帧渲染；数据来自系统 hilog 与 WMS 时间戳）。

### 1.2 RAG 问答响应（向量检索 + 云端生成端到端）

| 场景 | 耗时 | 说明 |
|---|---|---|
| 冷查询（首次） | 5-8 s | 含知识库 16 条首次 embedding（GLM embedding-2，16 次向量请求）+ 问题嵌入 + GLM 生成 |
| 热查询（知识库已嵌入） | 3-6 s | 仅问题嵌入（1 次）+ 向量召回（本地 O(n) 余弦）+ GLM 生成 |
| 断网/云端异常降级 | < 0.1 s | 本地关键词检索直答，零网络依赖 |

测量方式：UI 自动化点击快捷问题 → 3 秒粒度轮询界面"知识来源"出现（含约 1s 轮询开销，实际值略优于表中区间）。

### 1.3 跌倒检测链路

- 传感器采样周期 100 ms；判定状态机为 O(1) 阈值逻辑；
- 静止相确认窗口 ≈ 1.2 s（12 帧），即冲击发生后最迟约 1.3 s 内给出疑似跌倒判定；
- 判定→告警页路由 < 1 s（见截图 04：抓拍到的 10 秒倒计时进行中画面）；
- 告警升级通知在倒计时结束（10 s）后由 Notification Kit 发布，通知栏即时可见（截图 20）。

### 1.4 内存占用

应用运行中进程 Total RSS ≈ **37 MB**（模拟器实测，含 ArkUI 运行时与共享库；hidumper --mem）。数据层体量小（RDB 告警表 + 16 条知识库内存索引 + embedding 向量缓存约 100 KB 量级）。

## 三、体验与配置说明

### 3.1 体验方式（无账号体系，开箱即用）

1. 安装 `entry-default-signed.hap`（已签名）到 HarmonyOS 6+（API 20+）设备或模拟器；
2. 首次启动选择角色（老人/家属），此后自动记忆；切换角色：设置→应用→银龄守护→清除数据后重进；
3. 演示入口（评审演示快捷路径）：
   - 老人端底部【演示】模拟一次跌倒 / 模拟喊"救命"；
   - 问答页【🧪 示例识药】；
   - 家属端【演示】模拟接收一次老人端跌倒告警。

### 3.2 云端能力配置

- 云端 GLM（问答生成/识药/embedding）使用智谱开放平台 API Key，已内置（glm-4-flash / glm-4v-flash / embedding-2 均为免费额度模型）；
- Key 失效或断网时自动降级：向量检索→关键词检索→本地直答，全部功能不中断；
- 替换 Key：`entry/src/main/ets/service/LlmService.ets` 中 `GLM_API_KEY` 常量。

### 3.3 权限清单（最小化申请）

| 权限 | 授权方式 | 用途 |
|---|---|---|
| INTERNET | 安装时 | 云端 AI 问答 |
| ACCELEROMETER | 安装时（系统级） | 端侧跌倒检测 |
| MICROPHONE | 运行时弹框 | 端侧求救关键词识别（拒绝不影响其他功能） |
| DISTRIBUTED_DATASYNC | 运行时弹框 | 跨设备守护同步（拒绝降级纯本机） |
