# 银龄守护 · 体验配置说明

> 本说明面向评审与体验者，覆盖"零配置可直接看什么、云端 AI 如何配置、如何编译运行、已知限制"四件事。全程约 5 分钟可完成配置。

## 一、体验账号说明

本作品**无用户注册体系、不需要任何体验账号**：应用首次启动进入"角色选择"页，选择【老人端】或【家属端】即可直接体验全部功能（单设备双角色均可用，角色可随时在首页切换）。

## 二、零配置即可体验的功能（无需任何 Key）

以下能力全部在端侧本地运行，安装后即可演示：

| 功能 | 体验入口 |
|---|---|
| 跌倒检测 + 10 秒倒计时自救 | 老人端首页 →【演示】模拟跌倒 |
| 语音求救识别（端侧热词） | 老人端 →【演示】模拟喊"救命" |
| 健康看板（今日活动/心率/用药） | 老人端 → 健康页（演示模式 5 秒自动刷新模拟数据） |
| 家属告警接收 + 状态看板 | 切换家属端角色，实时查看告警与健康快照 |
| 元服务桌面卡片（2×2 守护状态） | 桌面长按应用图标 → 服务卡片 |
| 告警本地持久化 | 任意触发一条告警 → force-stop 重启应用，记录仍在 |
| 本地知识库用药问答（降级模式） | 老人端 → 用药问答 → 提问（如"阿司匹林和布洛芬能一起吃吗"） |

## 三、云端 AI 能力配置（可选，约 5 分钟）

为使语义召回、多模态识药、用药管家 Agent 达到完整效果，需配置一个大模型 API Key：

1. 打开[智谱开放平台](https://bigmodel.cn)，注册账号（免费）；
2. 在「API Keys」页面创建一个 Key 并复制；
3. 打开源码 `YinLingGuard/entry/src/main/ets/service/LlmService.ets`，第 14 行附近：
   ```ts
   const GLM_API_KEY = '';  // 在引号内粘贴你的 Key
   ```
4. 重新编译运行即可。

**不配置 Key 的影响**：应用不报错、不中断——云端问答自动降级为本地内置知识库关键词匹配（可正常回答常见用药问题），GLM-4V 拍照识药与 Agent 多步编排提示"云端未配置"。这正是本作品"三级降级"设计的直接体现。

> 注：提交包中的源码已对 API Key 脱敏（置空），Key 不随包分发。

## 四、编译与运行

- **工具**：DevEco Studio 6+（或 DevEco CLI），HarmonyOS SDK API 26（兼容 API 20+ 设备运行）；
- **步骤**：导入 `源代码/YinLingGuard` 工程 → 自动 Sync（首次联网下载依赖）→ 选择模拟器/真机 → Run；
- **签名**：真机运行需在 DevEco Studio 中配置自动签名（File → Project Structure → Signing Configs → Auto generate）；
- **路径要求**：工程路径必须为**纯英文**（hvigor 构建系统拒绝含中文的路径）——请勿将 `YinLingGuard` 目录移入中文路径再构建；
- **权限**：首次使用语音求救会弹出麦克风权限，请允许；跌倒检测使用加速度传感器无需权限弹窗。

## 五、已知限制（如实声明）

1. **分布式跨设备同步**需真实多设备（同华为账号可信组网）。本地模拟器不支持跨实例组网（已实测验证），故单设备上以"双角色切换"演示告警流转完整闭环；分布式代码已就绪（distributedKVStore + 权限声明），真机组网即用。详见《性能实测与测试说明》。
2. **语音求救**依赖端侧 Core Speech Kit，模拟器上以演示按钮注入等价事件，真机为真实识别。
3. **拍照识药**依赖摄像头与网络，模拟器上可用"示例识药"（内置示例图片）体验完整流程。
